# Task envelope template

This template is a subordinate derived view of an approved canonical Work Order. It never grants scope or authority.

```text
TASK_ENVELOPE
MISSION =
ASSIGNED_ROLE =
BASELINE =
SCOPE =
EXCLUSIONS =
INVARIANTS =
ACCEPTANCE =
REQUIRED_SKILLS_TOOLS =
VERIFICATION =
NEXT_AUTHORITY =
```

Copy only task-specific changing facts into a work message.
